# PLAN.md has become the spec

The design now lives in [`spec/`](spec/README.md), one topic per file, with
the section numbering preserved: a citation like `PLAN.md 2.2` or `§7.3`
resolves to the spec file whose name carries that number (`spec/02-…` §2.2,
`spec/07-…` §7.3). The index in `spec/README.md` maps every section.

The milestone histories and the measurements that shaped the design are in
this file's git history.
